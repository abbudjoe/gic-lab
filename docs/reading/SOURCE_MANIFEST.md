# Source Manifest Guide

Status: **verified metadata projection**

The canonical machine-readable source registry is [`../../manifests/sources.yaml`](../../manifests/sources.yaml). This page intentionally does not duplicate revisions, commits, hashes, licenses, or retrieval dates.

The pinned primary set is:

- GIC: *Critique of Agent Model*, arXiv `2606.23991v1`.
- SR²AM: *Efficient Agentic Reasoning Through Self-Regulated Simulative Planning*, arXiv `2605.22138v1`, plus the official pinned repository and released model revisions.
- SiRA: *General Agentic Planning Through Simulative Reasoning with World Models*, arXiv `2507.23773v3`, plus the official pinned repository.

The same SiRA paper used the SimuRA name/title in earlier versions. The project treats the v3 name and repository as current and records the naming history rather than inventing a second current prototype.

Paper hashes were computed from versioned arXiv PDFs in temporary storage on 2026-07-15; the PDF files were not copied into this repository. Repository and model revisions were resolved from their official remotes without downloading model weights.
