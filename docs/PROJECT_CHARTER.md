# Project Charter

## Mission

Determine, through controlled and reproducible experiments, which GIC-associated mechanisms are necessary, sufficient, learnable, and advantageous relative to matched external orchestration. The program treats GIC as a set of falsifiable architectural hypotheses, not as a conclusion to prove.

## Phase 0 objective

Create the research control plane before consuming paid compute: explicit source provenance, hypotheses, protocols, typed experiment state, artifact identity, compute accounting, validation, publication, and safety boundaries.

## Scientific principles

1. Prefer causal comparisons over demonstrations.
2. Match model, tool, token, call, latency, and compute budgets wherever the hypothesis requires it.
3. Measure predicted transitions against observed transitions rather than accepting plausible narratives as world-model evidence.
4. Preserve negative and inconclusive results when the protocol is valid.
5. Keep scientific claims, project decisions, and historical rationale in separate authority planes.
6. Distinguish lifecycle, evidence strength, and result outcome in data and prose.
7. Treat an implementation discrepancy as a contract question before treating it as model behavior.

## Initial research sequence

The provisional sequence is artifact audit, mechanism reproduction, cost-controlled causal baselines, prediction validity, then one isolated extension at a time. Multi-goal state, calibrated identity, a separately evaluated world model, bounded continual learning, simulated embodiment, and physical embodiment remain later hypotheses—not Phase 0 deliverables.

## Phase 0 non-goals

- Running SiRA, SR²AM, or any benchmark.
- Downloading model checkpoints.
- Training, fine-tuning, or reinforcement learning.
- Provisioning or mutating cloud resources.
- Finalizing a repository license, Phase 1 hypothesis, benchmark set, or provider architecture.
- Claiming reproduction, performance, efficiency, growth, or model quality.
