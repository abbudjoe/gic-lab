# Research Questions

These questions are a provisional research map, not approved Phase 1 hypotheses.

## Baseline mechanism

- **RQ-01:** Under matched inference budgets, when does self-regulated simulative planning improve the success–cost frontier over reactive, always-plan, rule-routed, and equal-token unstructured reasoning?
- **RQ-02:** Do structured predicted future states carry decision-relevant predictive information beyond plausible verbal rationalization?
- **RQ-03:** Does a learned internal configurator generalize better than an explicit external router when task difficulty or environment state shifts?

## Architecture boundary

- **RQ-04:** Which GIC state belongs in typed external control infrastructure, and which benefits from being learned or internalized?
- **RQ-05:** Does a separately trained transition model improve action selection when candidate actions and rollout budgets are controlled?

- **RQ-H2K — Progressive Harness-to-Kernel Internalization (planned/deferred):** Which
  externally orchestrated reasoning-control functions could eventually be represented
  inside a learned reasoning model while improving efficiency, generalization,
  adaptation, or scaffold independence without unacceptable loss of auditability,
  safety, or reversibility? Planning regulation is the first candidate mechanism. No
  active experiment, implementation, training, or later phase is authorized; the
  current package preserves trace and provenance evidence only. See
  [the option-preservation contract](H2K_OPTION_PRESERVATION.md).

## Long-horizon extensions

- **RQ-06:** Does explicit multi-goal portfolio state improve interruption, resumption, conflict handling, and deadline-weighted completion under fixed resources?
- **RQ-07:** Does a calibrated capability/identity state improve decisions, or introduce anchoring and error reinforcement?
- **RQ-08:** Can bounded adapter updates improve a recurring capability while preserving retention, calibration, and independently governed evaluation?

## Phase gates

Phase 0 answers no empirical research question. Phase 0.5 should reconcile primary sources and the human reading. A later Phase 1 protocol must select a small set of primary and secondary metrics, define matched budgets, declare exploratory versus confirmatory status, and obtain explicit approval before model or benchmark execution. RQ-H2K remains deferred and is not activated by Phase 1 trace capture.
